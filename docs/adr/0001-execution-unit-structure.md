# ADR-001: 실행 단위 구성

## 상태

승인

## 배경

논리 아키텍처는 다음 실패 격리를 요구한다.

- 집계가 중단돼도 이벤트 접수는 계속한다.
- 월간 정산 실패가 집계와 API에 영향을 주지 않는다.
- 데이터 처리가 중단돼도 마지막 집계 결과를 조회한다.

단일 프로세스, 책임·실패 단위별 분리, 논리 경계별 세밀한 분리를 검토했다.

## 결정

책임과 실패 단위에 따라 다음 프로세스로 분리한다.

- 이벤트 접수
- 현재 월 집계
- 월간 정산
- BFF/API + 인증·접근 통제
- 웹 대시보드

이벤트 발생기는 시스템 외부 도구로 둔다. 독립 실행할 필요가 없는 논리 경계는 관련 프로세스의 코드 모듈로 유지한다.

통신 방식과 저장소는 후속 ADR에서 결정한다.

## 결과

- 집계·배치·API 장애를 서로 격리할 수 있다.
- 실행 단위별 재시작과 확장이 가능하다.
- 논리 경계별 과도한 프로세스 분리를 피한다.
- 단일 프로세스보다 실행과 운영이 복잡해진다.
- 프로세스 간 통신과 데이터 일관성 관리가 필요하다.
