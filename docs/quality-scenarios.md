# 품질 시나리오

## 1. 목적

데이터 파이프라인, 조회, 배치 검증이 만족해야 할 품질과 검증 기준을 정의한다.

## 2. 검증 기준

- 테넌트: 소규모 회사 1,000개
- 인스턴스: 회사당 10~50대, 평균 20대
- 개발용 데이터: 1,000만 건으로 빠르게 기능 검증
- 성능 검증 데이터: 1억 건
- 예상 월간 데이터: 사용량 이벤트 약 8억 6,000만 건
- 정상 입력 부하: 초당 약 330건
- 최대 입력 부하: 지연 이벤트가 몰릴 때 초당 1,000건
- API 부하: 서로 다른 테넌트의 동시 사용자 500명
- 금액 계산은 동일한 사용량과 단가를 사용한다.
- 수치는 포트폴리오 부하 테스트의 초기 목표이며 측정 결과와 함께 조정한다.

## 3. 시나리오

| ID | 상황 | 기대 동작 | 검증 기준 | 우선순위 |
|---|---|---|---|---|
| QS-01 | 동일한 이벤트가 반복 수신된다. | 이벤트를 한 번만 사용량과 금액에 반영한다. | 중복 반영 0건 | 핵심 |
| QS-02 | 열린 월의 이벤트가 최대 10분 늦거나 순서가 바뀌어 도착한다. | 도착 순서와 관계없이 집계를 보정한다. | 수신 후 1분 이내 반영, 최종 오차 0원 | 보조 |
| QS-03 | 초당 1,000건의 이벤트가 10분간 들어온다. | 이벤트를 유실하지 않고 지속해서 처리한다. | 유실 0건, 99%가 10초 이내 집계 반영 | 핵심 |
| QS-04 | 이벤트 1억 건이 저장된 상태에서 사용자가 금액을 조회한다. | 원본 전체를 매번 계산하지 않고 결과를 반환한다. | 서로 다른 테넌트의 동시 사용자 500명에서 응답시간 p95 1초 이하 | 핵심 |
| QS-05 | 월간 배치가 처리 도중 실패한다. | 안전하게 재실행하여 검증과 확정을 완료한다. | 중복 결과 0건, 정상 실행 결과와 차이 0원 | 핵심 |
| QS-06 | 동일한 사용량과 가격 조건으로 배치를 다시 실행한다. | 이전과 동일한 월간 금액을 생성한다. | 실행 간 금액 차이 0원 | 핵심 |
| QS-07 | 사용자가 다른 테넌트의 데이터를 요청한다. | 요청을 거부하고 데이터를 반환하지 않는다. | 노출 데이터 0건 | 보조 |
| QS-08 | 운영자가 월간 금액의 계산 근거를 확인한다. | 사용량과 적용 단가까지 추적할 수 있게 한다. | 근거가 없는 확정 금액 0건 | 보조 |
| QS-09 | 사용자가 이번 달 누적 금액을 조회한다. | 이번 달 1일부터 최근 집계 완료 시점까지의 예상 금액과 기준 시각을 반환한다. | 데이터 지연 5분 이하, 월말 배치 결과와 차이 0원 | 핵심 |

## 4. 우선 검증 대상

QS-01, QS-03, QS-04, QS-05, QS-06, QS-09를 우선 구현하고 측정한다.
