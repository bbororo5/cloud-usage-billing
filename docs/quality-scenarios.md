# 품질 시나리오

수치는 포트폴리오의 초기 검증 목표이며 측정 결과에 따라 조정한다.

## 기준 환경

| 항목 | 기준 |
|---|---|
| 고객 규모 | 회사 1,000개, 회사당 인스턴스 10~50대·평균 20대 |
| 데이터 | 개발 1,000만 건, 성능 검증 1억 건, 예상 월간 약 8억 6,000만 건 |
| 이벤트 부하 | 정상 초당 약 330건, 최대 초당 1,000건 |
| API 부하 | 서로 다른 회사의 동시 사용자 500명 |

## 시나리오

| ID | 상황과 기대 동작 | 통과 기준 | 중요도 |
|---|---|---|---|
| QS-01 | 동일 이벤트는 여러 번 받아도 한 번만 반영한다. | 중복 반영 0건 | 핵심 |
| QS-02 | 최대 10분 늦거나 순서가 바뀐 이벤트도 열린 월의 집계를 보정한다. | 수신 후 1분 이내 반영, 오차 0원 | 보조 |
| QS-03 | 초당 1,000건이 10분간 들어와도 계속 처리한다. | 유실 0건, 99%가 10초 이내 반영 | 핵심 |
| QS-04 | 이벤트 1억 건에서 사용자 500명이 금액을 조회한다. | 응답시간 p95 1초 이하 | 핵심 |
| QS-05 | 월간 배치가 중단되어도 안전하게 재실행한다. | 중복 0건, 정상 실행과 차이 0원 | 핵심 |
| QS-06 | 같은 사용량과 단가로 다시 계산하면 같은 결과를 만든다. | 실행 간 차이 0원 | 핵심 |
| QS-07 | 다른 회사의 데이터 요청을 거부한다. | 노출 0건 | 보조 |
| QS-08 | 확정 금액에서 사용량과 단가를 추적한다. | 근거 없는 금액 0건 | 보조 |
| QS-09 | 최근 집계 기준의 월 누적 예상 금액과 기준 시각을 반환한다. | 지연 5분 이하, 월말 배치와 차이 0원 | 핵심 |

우선 검증 대상은 QS-01, QS-03, QS-04, QS-05, QS-06, QS-09다.
