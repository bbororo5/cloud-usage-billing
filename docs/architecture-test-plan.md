# Architecture Test Plan

아키텍처 드라이버를 구현 전 테스트 계획과 연결하고, 구현 후 자동으로 검증한다.

| 대상 | 검증 | 통과 기준 | 실행 시점 |
|---|---|---|---|
| DR-01 | 중복·지연·순서 변경 처리와 배치 비교 | 중복 0건, 금액 차이 0원 | 매 커밋 |
| DR-02 | 초당 330건 지속 입력과 1,000건 최대 입력 | 유실 0건, 99%가 10초 이내 반영 | 주요 변경 후 |

| 귀속 격리 | 미귀속·중복 점유 이벤트 격리 및 월간 확정 차단 | 미귀속 상태 확정 0건, 오류 격리 100% | 매 커밋 |
| 구조 | 모듈 책임과 의존 관계 검사 | 금지된 의존 0건 | 매 커밋 |

## 운영

| 구분 | 범위 |
|---|---|
| 빠른 테스트 | 작은 데이터로 정확성·재처리·회사 분리·점유 귀속·역할 권한을 매 커밋 검증 |
| 통합 테스트 | 실제 데이터 흐름의 실패·복구·미귀속 차단을 주요 변경 후 검증 |
| 성능 테스트 | 처리량·동시 조회·대용량 성능을 별도로 실행하고 기록 |

## 준비 순서

1. 이벤트 형식 확정 후 테스트 이벤트와 발생기를 만든다.
2. 모듈 책임 확정 후 구조 테스트를 만든다.
3. [API 계약과 권한표](api-contract.md)를 기준으로 권한·부하 테스트를 만든다.
4. 점유 이력 매핑, 미귀속 차단, 테넌트 격리(Row Policy/RLS), 스트리밍·배치 재실행 테스트를 만든다.

모든 ADR에는 관련 테스트와 통과 기준을 함께 기록한다.

## 현재 자동화 기반

| 대상 | 파일 | 현재 검증 |
|---|---|---|
| PostgreSQL | `database/postgresql/schema_test.sql` | RLS, 마지막 Admin, 가격 구간, 실행 재시도, 단일 확정 |
| ClickHouse | `database/clickhouse/schema_test.sql` | 전달 중복 제거, VM 출처 격리, 가격 사본 버전 |
| 조회·배치 | `database/clickhouse/queries` | 비용·월간 총액·안정 커서 쿼리 실행 |
| 이벤트 계약 | `contracts/v1` | JSON Schema와 예제 일치 |
| API 계약 | `contracts/openapi.yaml` | OpenAPI lint |

단계 1에서 이 검증을 Testcontainers 기반 통합 테스트와 CI 명령으로 묶는다.
