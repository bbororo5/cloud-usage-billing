# Architecture Drivers

품질 시나리오 중 데이터 흐름과 시스템 구조를 결정하는 요구만 선정한다.

| ID | 드라이버 | 반드시 지킬 기준 | 근거 |
|---|---|---|---|
| DR-01 | 사용량·금액 정확성 | 중복·지연·재처리에도 결과가 같고 계산 근거를 추적한다. | QS-01, 02, 06, 08, 09 |
| DR-02 | 지속적인 이벤트 처리 | 정상 초당 330건과 최대 1,000건을 10분간 유실 없이 처리하고 밀린 데이터를 복구한다. | QS-02, 03 |
| DR-03 | 빠른 비용 조회 | 배치 실행 중에도 대시보드는 p95 1초, 31일 비용 탐색은 p95 2초를 지키고 월 누적 기준 시각을 제공한다. | QS-04, 09, 12, 13 |
| DR-04 | 안전한 재처리 | 처리 상태를 기록하고 스트리밍·배치 실패 후 중복 없이 재실행해 원본에서 다시 계산한다. | QS-01, 05, 06 |
| DR-05 | 멀티테넌시 격리 | 확인된 회사 범위를 수집·집계·정산·캐시·조회 전 과정에 유지하고 다른 회사의 데이터 접근을 막는다. | QS-07 |
| DR-06 | 일관된 역할 권한 | 회사 소속별 역할을 기본 차단으로 검사하고 변경된 권한을 즉시 반영·기록한다. | QS-10, 11 |

설계 순서는 `정확성·재처리 → 이벤트 처리·저장 → 조회`로 하며 회사 격리와 역할 권한은 전 단계에서 검증한다.
