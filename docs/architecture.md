# Architecture

## 1. 시스템 경계

대상 시스템은 사용량 이벤트를 받아 비용을 계산하고 인증된 사용자에게 웹 대시보드로 제공한다.

### 경계 안

- 이벤트 수신·검증, 스트리밍 집계, 예상 금액 계산
- 월간 배치 검증과 확정 금액 생성
- 고정 가격표와 회사별 데이터 관리
- BFF/API와 내부 사용자 인증·역할 검사
- 최소 웹 대시보드와 Admin의 구성원 권한 관리

### 경계 밖

- 실제 클라우드와 클라우드 사업자
- 사용량 이벤트 발생기
- 실제 결제·세금·환불 시스템
- 외부 인증 제공자
- 시스템을 사용하는 Admin과 Viewer

### 경계 연결

| 외부 대상 | 시스템과의 연결 |
|---|---|
| 이벤트 발생기 | CloudEvents 형식의 사용량 이벤트 발행 |
| Admin·Viewer | 웹 대시보드를 통해 인증·조회·권한 관리 |

이벤트 발생기는 운영 경계 밖에 두되 재현과 성능 검증을 위해 프로젝트 저장소에 함께 제공한다. 실제 클라우드 대신 여러 회사의 정상·중복·지연·오류 이벤트와 부하를 재현한다.

인증은 등록된 사용자 로그인과 역할 검사만 구현한다. 회원가입·계정 복구·MFA·외부 인증 연동은 다루지 않는다.
