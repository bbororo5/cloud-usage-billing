# Cloud Usage Billing

클라우드 사용량 이벤트를 수집·집계하고 최근 집계 기준의 월 누적 예상 금액과 월간 확정 금액을 제공하는 포트폴리오 프로젝트입니다.

현재는 주요 아키텍처 결정을 마치고 구현 계약과 테스트 기반을 준비하는 단계입니다.

## 개발 환경

- Java 21
